# Animated React Website

A modern and visually engaging creative agency website built using React, Vite, Tailwind CSS and GSAP.

## 🚀 Features

- Modern and responsive UI
- Smooth GSAP animations
- Animated fullscreen navigation menu
- Multiple pages using React Router
- Creative hero section with background video
- Animated project showcase
- Scroll-based animations
- Dynamic image transitions
- Responsive design for desktop and mobile
- Custom fonts and modern typography

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- GSAP
- React Router
- JavaScript
- HTML5
- CSS3
